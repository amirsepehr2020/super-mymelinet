# Sepehr × Amir — Live Phone Status

داشبورد خصوصی برای نمایش زنده وضعیت دو گوشی: سپهر و امیر.

## چه چیزهایی نمایش داده می‌شود؟
- آنلاین/آفلاین بودن بر اساس heartbeat
- وصل یا قطع بودن اینترنت گوشی
- روشن یا خاموش بودن صفحه
- مدت زمان اتصال فعلی
- بروزرسانی خودکار داشبورد

## نکته مهم
یک وب‌سایت به‌تنهایی نمی‌تواند وضعیت واقعی گوشی را ۲۴ ساعته بفهمد. برای داده واقعی باید یک **اپ اندروید همراه** روی هر دو گوشی نصب شود و heartbeat و وضعیت شبکه/صفحه را به API ارسال کند. محدودیت‌های باتری و اجرای پس‌زمینه اندروید می‌تواند روی دقت heartbeat اثر بگذارد.

## API
`worker.js` برای Cloudflare Worker نوشته شده و به Cloudflare D1 نیاز دارد.

1. یک D1 database بسازید و `schema.sql` را اجرا کنید.
2. binding دیتابیس را با نام `DB` به Worker وصل کنید.
3. یک Worker secret با نام `STATUS_TOKEN` بسازید.
4. Worker را روی دامنه API قرار دهید.
5. در `app.js` مقدار `API_BASE` را به آدرس Worker تغییر دهید.

## مرحله بعد
باید اپ اندروید companion برای هر دو گوشی ساخته شود؛ با شناسه‌های `sepehr` و `amir`. اپ فقط telemetry لازم برای این داشبورد را ارسال می‌کند: heartbeat، وضعیت اینترنت و روشن/خاموش بودن صفحه.
